🏗️ Technical Architecture Summary

📐 For comprehensive technical architecture with diagrams and code examples, see System Architecture

Architecture Highlights

5-Layer Architecture Pattern:

  1. Presentation Layer - React Components, Responsive UI
  2. Application Layer - Next.js App Router, Server Components
  3. Business Logic Layer - Server Actions, Workflow Engine
  4. Data Access Layer - Type System, Mock Data, Validators
  5. Cross-Cutting Concerns - Auth, RBAC, Logging, Errors

Technology Stack:

  • Next.js 14 + React 18 + TypeScript 5.8+
  • Tailwind CSS + Shadcn/ui + Radix UI
  • Zustand (Global State) + React Query (Server State)
  • React Hook Form + Zod Validation

Key Architectural Decisions:

  • ✅ Server-First Approach (Server Components by default)
  • ✅ Centralized Type System (/lib/types/) with guards and validators
  • ✅ Centralized Mock Data (/lib/mock-data/) with factory functions
  • ✅ Role-Based Access Control with 7 user roles

🔒 Security Implementation

RBAC System

7 User Roles:

  1. System Administrator (Full Access)
  2. Financial Manager (Financial + Reports)
  3. Department Manager (Department-level)
  4. Purchasing Staff (PR/PO Limited)
  5. Chef (Recipes + View Inventory)
  6. Counter Staff (View Only)
  7. Staff (Minimal Access)

Security Features:

  • ✅ Role-based permissions
  • ✅ Department/Location context switching
  • ✅ Audit trails
  • ✅ Type-safe validation
